# web

Die Oberflaeche: React, TypeScript, Vite, Tailwind und shadcn/ui.

```powershell
npm install
npm run dev        # http://localhost:5173
npm run test       # Vitest
npm run lint
npm run build      # statische Dateien nach dist/
```

Die Daten kommen aus `public/data/` und entstehen mit `python -m collector publish`
im Hauptverzeichnis. Naeheres steht in der README dort.
